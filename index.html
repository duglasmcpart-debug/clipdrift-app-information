ClipDrift Local

A desktop tool for editing stream clips and sending finished vertical videos to the operator’s YouTube channel.

How it works

ClipDrift processes selected video files on the operator’s computer. It finds possible highlights, prepares captions, renders vertical clips, and uploads finished videos with the operator’s chosen channel, metadata and visibility.

YouTube connection

Google sign-in lets ClipDrift identify the connected YouTube channel, upload approved videos and check whether YouTube processed them. ClipDrift uses YouTube API Services.
